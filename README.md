# Brand contrast repair

A small experimental browser tool for checking solid text and background colors and suggesting lighter or darker text colors for the WCAG AA normal-text contrast threshold.

Try it: https://brand-contrast-repair.small-business-accessibility-check.workers.dev

The tool processes the chosen colors in the browser. It checks contrast only, not overall accessibility or legal compliance. Transparency, gradients, images and non-text elements require separate evaluation. Suggestions are simple interpolations toward black or white, not a guarantee of visual or brand suitability.

This is an early experiment; its behavior has not yet been independently verified. Feedback and reproducible issues are welcome in this repository.
